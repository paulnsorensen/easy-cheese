# Structurizr export command

This page records the Structurizr documentation page for the `export` command, last verified 2026-10-19. The page supports the claims about the free export formats and the open-source status of Structurizr.
Canonical source: [export | Structurizr](https://docs.structurizr.com/export)

## Claims used from the Structurizr export page

The Structurizr export page describes "the free and open source export command". It exports workspace views to PlantUML, C4-PlantUML, Mermaid, WebSequenceDiagrams, a static HTML site, JSON, and themes. It exports PNG and SVG "using the Structurizr browser-based renderer".

- Invocation: `export -workspace workspace.dsl -format mermaid` (flags `-workspace`, `-format`, `-output`).
- The page notes that export formats "do not support all available shapes/features when compared to Structurizr playground, local, and server".

Related pages in the same docs (fetched 2026-10-19): the `local` command is "free and open source" and "equivalent to the previous Structurizr Lite tooling"; the `server` command has a free open core when built from source and licensed prebuilt binaries; Structurizr Lite and on-premises are listed as end of life.
