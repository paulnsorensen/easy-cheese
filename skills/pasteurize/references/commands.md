# `/pasteurize` bundle commands

`scripts/render_generated_regions.py` generates this file from the static `COMMANDS` manifest in `src/easy_cheese/skills/pasteurize/commands.py`. Do not edit this file. Run each command as `python3 skills/pasteurize/scripts/pasteurize.pyz <command> [args...]`. Each command returns an integer exit status. Pass `--help` to a command for its arguments and output format. Keep worked examples in the skill instructions.

| Command | Purpose |
| --- | --- |
| `debug-tag-sweep` | Scan a tree for surviving instrumentation tags |
| `pasteurize-route` | Size a /pasteurize investigation into fan-out lanes (JSON in, JSON out) |
| `repro-rerun` | Re-run a repro command N times and emit a structured verdict |
