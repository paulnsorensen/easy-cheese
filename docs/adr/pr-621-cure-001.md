# Put handoff mode before the artifact

## ADR-001: Separate mode metadata from orientation [status: accepted]

- **Context:** Valid orientation text can start with `mode: parallel`. The PR parser treats this text as metadata.
- **Decision:** Put optional `mode:` after `next:` and before mandatory `artifact:`. Keep legacy four-line handoffs unchanged.
- **Alternatives:** A comment delimiter adds syntax. A parser guess cannot distinguish metadata from identical orientation text.
- **Consequences:** Both handoff readers use the same explicit position. The ambiguous, unmerged PR format does not receive heuristic compatibility.

This corrects finding B1 in [PR #621](https://github.com/paulnsorensen/easy-cheese/pull/621).
The affected readers are `src/easy_cheese/shared/handoff.py` and `src/easy_cheese/skills/wheypoint/projection.py`.

The Hallouminate corpus targets the parent checkout, not this PR worktree.
This tracked file records the decision without a write to the wrong checkout.
